# Kohan approved avatar sheets

These are the approved supplemental WebP strips retained as editable runtime references for the website avatar.

- The website controller targets only the Kohan CV assistant avatar.
- Hover does not trigger jumping.
- Click chooses one random approved action.
- Idle actions run every 30–75 seconds; every third completed idle interval runs Russian Roulette.
- Russian Roulette randomly dry-clicks or fires toward the camera. A fire is followed by scared, then confused/IDK.
- Walking patrol uses the approved atlas only: two short visible steps right, then two back to the exact origin.
- Dragging uses annoyed/scared artwork and does not count as a click.
- Close plays wave/snap/smoke before the overlay closes.

Identity-drift generations are excluded. The approved atlas and original supplemental artwork remain the visual source of truth.
