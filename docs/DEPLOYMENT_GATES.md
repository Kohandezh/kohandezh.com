# Deployment Gates — Kohandezh.com Knowledge Platform

> The exact gates every change must pass **before** reaching production. Local work is autonomous (Agent.md addendum §1); production deployment is gated (addendum §19). Never deploy unattended unless **all** gates pass.

## Gate sequence

```
local edit → Tier 0 lint → Tier 1 sync parity → Tier 2 Layer A integrity
   → Tier 3 Layer B tests → Tier 4 perf smoke → STAGING (if exists)
   → pre-deploy checklist → DEPLOY → post-deploy verify → CANARY
```

## G1 — Code quality (must pass)
- [ ] `python3 -m py_compile` on any changed `.py`
- [ ] `php -l` clean on all changed/new `.php`
- [ ] JS syntax check on changed `.js`
- [ ] Forbidden-pattern grep returns nothing (eval/exec/remote file_get_contents/hardcoded secrets)

## G2 — Sync parity (must pass, every Layer A change)
- [ ] `sync-from-static.py --dry-run` reports 0 errors; deletion list reviewed
- [ ] Temp-theme controlled test: corrupted → regenerated byte-identical; 0 unexpected diffs
- [ ] Real-theme guarded run: md5 before/after matches expectations; no unexplained changes

## G3 — Layer A integrity (must pass)
- [ ] Homepage + 9 locales + blog + portfolio + PSN + Certificates return 200
- [ ] Canonical/hreflang/JSON-LD counts unchanged on CV pages
- [ ] `.htaccess` 301 redirects intact
- [ ] No broken internal links
- [ ] Intentional 404 still 404

## G4 — Layer B tests (must pass when Layer B changes)
- [ ] Plugin activate/deactivate idempotent; no errors
- [ ] REST routes resolve; pagination + permissions enforced
- [ ] No `unverified` claims in public reads
- [ ] Isolation: Layer B assets absent from Layer A pages
- [ ] JSON-LD parses; stable `@id`; no conflicting entities

## G5 — Performance (must not regress)
- [ ] Homepage payload within baseline ±X%
- [ ] No new global enqueues
- [ ] No new autoloaded options; no front-end full-site scans

## G6 — Pre-deploy (production — all required)
- [ ] Production backup (files + DB) confirmed
- [ ] Rollback procedure tested (ROLLBACK.md)
- [ ] No destructive DB migration
- [ ] **No permalink change**
- [ ] **No homepage replacement**
- [ ] No unresolved high-severity security issue
- [ ] `kohandezh-ai-hub` plugin conflict re-checked (PRODUCTION_UNKNOWNS U12)
- [ ] SEO/multilingual plugin ownership decided (U2/U3)
- [ ] Deployment scope documented
- [ ] Dry-run + local tests pass
- [ ] Staging verified (if staging exists)

## G7 — Post-deploy verify
- [ ] Production homepage intact; locales intact
- [ ] Layer B routes return 200; REST responds
- [ ] Sitemap valid; `llms.txt` valid
- [ ] Canonical/hreflang correct in production source
- [ ] Monitor 24h: error log clean, no perf regression

## Hard stop (do NOT deploy if any is true)
Any condition in Agent.md addendum §20 (prod data risk, irreversible migration, missing credentials, ambiguous target, exposed secret, critical CVE, legal block, unverifiable required fact, repo corruption, resource exhaustion, ambiguous ownership, destructive-only path).
